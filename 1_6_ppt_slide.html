TOPIC 36 • 연산장치 (ALU) ★출제 1위

누산기(AC) & 연산 회로 4총사

1. 누산기 (AC, Accumulator) ★★★
• 연산된 결과(중간 및 최종 결과)를 일시적으로 기억하는 레지스터
• 시험에 "연산 결과 일시 저장" 문구가 나오면 무조건 누산기!
2. 가산기 & 보수기
• 가산기 (Adder): 2진수의 덧셈을 수행하는 논리 회로
• 보수기 (Complementer): 뺄셈을 수행하기 위해 숫자를 보수로 변환
3. 상태 레지스터 (Status Register)
• 연산 과정에서 발생하는 부호, 0, 캐리(올림수), 오버플로 등 상태 플래그 보관
⚙️ ALU 핵심 구성 요소 요약표
구성 요소 핵심 기능 및 시험 정답
누산기 (AC) ★ 연산된 결과를 일시적으로 저장하는 레지스터
가산기 덧셈(Addition) 연산 회로
보수기 뺄셈(Subtraction) 연산을 위한 보수 변환 회로
상태 레지스터 연산 도중 발생하는 올림수/오버플로 등 상태값 기억
💡 기출 지문 정답: "연산 장치에서 덧셈 연산 후 그 결과를 일시적으로 저장하는 레지스터는 누산기(Accumulator)이다."
TOPIC 37 • 주기억장치 (MAIN MEMORY)

비휘발성 ROM vs 휘발성 RAM

1. ROM (Read Only Memory) — 비휘발성
• 전원이 차단되어도 데이터가 지워지지 않는 비휘발성 메모리
• 읽기 전용, BIOS(기본 입출력 시스템), 펌웨어(Firmware) 저장
• EPROM: 자외선으로 내용 수정 / EEPROM: 전기로 내용 수정
2. RAM (Random Access Memory) — 휘발성
• 전원이 꺼지면 기억된 내용이 모두 소멸하는 휘발성 메모리
• 사용자가 자유롭게 읽고 쓰기(Read/Write) 가능
💡 펌웨어(Firmware)의 정의와 특징
• 성격: 하드웨어와 소프트웨어의 중간적 특성
• 저장 위치: 주로 EEPROM (플래시 ROM)에 저장
• 장점: 하드웨어 교체 없이 소프트웨어 업데이트만으로 기기 성능과 기능을 향상시킬 수 있음
💡 기출 지문 정답: "전기를 이용하여 기억된 내용을 여러 번 수정할 수 있는 ROM은 EEPROM이다."
TOPIC 37 • RAM 정밀 비교 ★출제 1위

캐시 메모리 SRAM vs 주기억장치 DRAM

1. SRAM (Static RAM, 정적 램)
• 구성 소자: 플립플롭 (Flip-Flop) 회로
• 재충전: 재충전 필요 없음
• 특징: 속도가 대단히 빠름, 고가, 적은 용량
• 사용처: 캐시 메모리 (Cache Memory)
2. DRAM (Dynamic RAM, 동적 램)
• 구성 소자: 콘덴서 (커패시터)
• 재충전: 주기적인 재충전(Refresh) 필수!
• 특징: 대용량, 저렴한 가격, 상대적으로 느림
• 사용처: 일반 PC의 주기억장치 (메인 메모리)
⚖️ SRAM vs DRAM 완전 비교표
비교 항목 SRAM (정적 램) DRAM (동적 램)
구성 회로 플립플롭 (Flip-Flop) 콘덴서 (Capacitor)
재충전(Refresh) 필요 없음 주기적 재충전 필수 ★
접근 속도 매우 빠름 보통
가격 / 집적도 고가 / 저집적도 (소용량) 저렴 / 고집적도 (대용량)
주요 용도 ★ 캐시 메모리 (Cache) 일반 PC 주기억장치
💡 기출 지문 정답: "DRAM은 콘덴서의 전하 방전을 막기 위해 주기적으로 재충전(Refresh)이 필요하다."
TOPIC 38 • 보조기억장치 ★기출 빈출

자기 회전 HDD vs 반도체 SSD

1. 하드디스크 (HDD) — 기계식 자기 저장
• 자성 물질이 코팅된 원판(플래터)을 모터로 회전시켜 헤드로 읽고 씀
• 동심원 형태의 트랙(Track)과 부채꼴 모양의 섹터(Sector)로 구성
• 기계적 소음, 발열, 외부 충격에 취약
2. SSD (Solid State Drive) — 반도체 저장 ★
• 기계적 모터 부품 없이 순수 반도체 플래시 메모리 칩으로 구성
• 읽기·쓰기 속도가 HDD 대비 압도적으로 빠름
• 무소음, 저전력, 내충격성 우수, 불량 섹터 미발생 ★
💾 HDD vs SSD 주요 특성 비교
비교 항목 하드디스크 (HDD) SSD
저장 매체 자기 원판 (플래터) 반도체 플래시 메모리
전송 속도 느림 (물리적 회전) 매우 빠름 (전자적 전송)
소음 / 전력 모터 회전 소음 있음 무소음, 저전력
불량 섹터 ★ 충격 시 발생 가능 물리적 불량 섹터 없음
💡 기출 지문 정답: "SSD는 반도체 메모리를 사용하여 HDD보다 속도가 빠르고 충격에 강하며 소음이 없다."
TOPIC 38 • 인터페이스 & 파티션

SATA 직렬 포트 & 디스크 파티션 원칙

1. SATA (Serial ATA) 인터페이스 ★
• HDD와 SSD를 메인보드에 연결하는 직렬(Serial) 전송 방식
• 컴퓨터 전원이 켜진 상태에서 장치 연결/분리 가능한 핫 스왑(Hot Swap) 지원
2. 디스크 파티션(Partition) 3대 원칙 ★
• 개념: 하나의 물리 디스크를 여러 개의 논리 영역으로 분할
• 다중 OS: 파티션마다 서로 다른 운영체제 설치 가능 (Windows + Linux)
• 파일 시스템: 한 파티션에는 오직 한 가지 파일 시스템만 사용 (포맷 필수)

TOPIC 39 • 특수 기억장치 ★출제 1위

캐시 메모리 & 가상 메모리(Virtual)

1. 캐시 메모리 (Cache Memory) — SRAM
• CPU와 주기억장치 간의 속도 차이 극복
• 자주 사용하는 명령어/데이터를 임시 보관하여 시스템 속도 향상
2. 가상 메모리 (Virtual Memory) ★★★
• 보조기억장치(HDD/SSD)의 일부를 주기억장치처럼 사용
• 실제 주기억장치 물리 용량보다 훨씬 더 큰 대용량 프로그램 실행 가능
3. 플래시 메모리 (Flash Memory)
• EEPROM 기반 비휘발성 반도체, 저전력·고속, USB/SD카드/스마트폰 저장장치

메모리 핵심 출제 키워드
캐시 메모리 CPU와 주기억장치 사이 속도 차이 완화 (SRAM)
가상 메모리 ★ 보조기억장치를 주기억장치처럼 사용하여 큰 프로그램 실행
버퍼 메모리 두 장치 사이의 데이터 전송 속도 차이 해결

TOPIC 39 • 특수 기억장치 ★단골

연관 메모리 (내용 기반 검색)

1. 연관 메모리 (Associative Memory)의 정의 ★
• 일반 메모리처럼 기억장치 주소(Address)로 접근하지 않고
• 저장된 내용(Content)의 일부를 제시하여 데이터를 병렬 검색하는 고속 메모리
2. 다른 명칭 및 특징
• CAM (Content Addressable Memory) 이라고도 부름
• 주소 변환 과정이 생략되므로 정보 검색 속도가 매우 빠름
• 하드웨어 회로가 복잡하여 고가임

TOPIC 40 • 입력 장치 (INPUT DEVICES)

광학 판독기 & 이미지 입력 장치

1. 마크 및 문자 광학 판독 장치
• OMR (광학 마크 판독기): 시험 답안지 컴퓨터용 사인펜 마킹 판독
• OCR (광학 문자 판독기): 지로용지나 인쇄된 문자 광학 인식
• MICR (자기 잉크 문자 판독기): 은행 수표의 마그네틱 잉크 문자 인식
2. 그래픽 & 이미지 입력 장치
• 스캐너 (Scanner): 사진/도면을 디지털 그래픽 데이터로 변환
• 디지타이저 (Digitizer / 타블렛): CAD 도면 설계용 좌표 입력 장치

TOPIC 41 • 출력 장치 (OUTPUT DEVICES)

픽셀·해상도 & 프린터 속도 규격

1. 모니터 해상도 핵심 원리 ★
• 픽셀 (Pixel, 화소): 화면을 구성하는 최소 단위
• 해상도 (Resolution): 픽셀 수가 많을수록 화면이 선명해지고, 상대적으로 아이콘과 텍스트의 표시 크기는 작아짐!
2. 레이저 프린터 & 단위 규격
• 레이저 프린터: 복사기 원리로 토너를 종이에 전사하는 비충격식
• 해상도 단위: DPI (Dots Per Inch) — 1인치당 인쇄 점 수
• 속도 단위: PPM (분당 페이지 수), IPM (ISO 표준 분당 이미지 수)
• LPM (Lines Per Minute): 분당 출력 줄 수 (라인 프린터)

Q1. 누산기(AC)가 기억하는 대상
"누산기(Accumulator)는 다음에 실행될 명령어의 주소 번지를 기억하는 레지스터이다." (O / X?)
정답: X (누산기는 연산 결과 저장!)
다음 명령 주소는 프로그램 카운터(PC)이며, 누산기는 '연산 결과'를 일시 저장합니다!
Q2. SRAM의 재충전 회로 필요성
"캐시 메모리로 사용되는 SRAM은 전하 방전을 막기 위해 주기적으로 재충전(Refresh) 회로가 필요하다." (O / X?)
정답: X (재충전은 DRAM!)
SRAM은 플립플롭 구조라 재충전이 필요 없으며, 재충전이 필요한 것은 DRAM입니다!
Q3. SSD의 물리적 불량 섹터
"SSD는 반도체 메모리 칩을 사용하므로 HDD와 달리 물리적인 불량 섹터가 발생하지 않는다." (O / X?)
정답: O (정확한 설명!)
