TOPIC 48 • 링커 & 로더

링커(결합 모듈화) vs 로더(메모리 적재)

1. 링커 (Linker) — 연결 편집기 ★
• 컴파일러가 생성한 목적 프로그램과 시스템 라이브러리를 결합
• 컴퓨터가 즉시 실행할 수 있는 실행 가능한 로드 모듈(.exe 등)을 생성
2. 로더 (Loader) — 메모리 적재기 ★
• 실행 가능한 로드 모듈에 주기억장치 번지(주소)를 할당하여 메모리에 적재
• 프로그램이 CPU에서 실제로 실행될 수 있도록 준비 완료
⚖️ 링커 vs 로더 역할 핵심 대조표
구분 입력 ➔ 출력 핵심 기능
링커 (Linker) 목적 코드 ➔ 로드 모듈 라이브러리 결합, 실행 모듈 제작
로더 (Loader) 로드 모듈 ➔ 메모리 적재 주소 할당, 주기억장치에 올림
💡 기출 지문 정답: "실행 가능한 프로그램을 주기억장치에 적재(Load)하여 실행 준비를 마치는 프로그램은 로더(Loader)이다."
TOPIC 49 • 번역 방식 ★출제 1위

컴파일러 vs 인터프리터 5대 비교

1. 컴파일러 (Compiler) — 일괄 번역
• 번역 단위: 프로그램 전체를 한꺼번에 번역
• 목적 프로그램: 생성함 (.obj, .exe)
• 속도: 번역 속도는 느리지만, 실행 속도는 매우 빠름
• 해당 언어: C, C++, FORTRAN, COBOL, PASCAL
2. 인터프리터 (Interpreter) — 행 단위 번역
• 번역 단위: 프로그램을 한 줄씩(행 단위) 번역
• 목적 프로그램: 생성하지 않음!
• 속도: 번역 속도는 빠르지만, 실행 속도는 느림
• 해당 언어: Python, BASIC, LISP, APL
⚖️ 컴파일러 vs 인터프리터 5대 비교표
비교 항목 컴파일러 인터프리터
번역 단위 프로그램 전체 한 줄씩 (행 단위)
목적 프로그램 ★ 생성함 (기계어 파일) 생성하지 않음
번역 속도 느림 빠름
실행 속도 ★ 매우 빠름 느림
대표 언어 C, C++, FORTRAN Python, BASIC
💡 기출 지문 정답: "인터프리터는 프로그램을 행 단위로 번역하여 즉시 실행하며 목적 프로그램을 생성하지 않는다."
TOPIC 50 • 객체 지향 (OOP)

객체 지향 프로그래밍 4대 핵심 특성

1. 객체 지향 (Object-Oriented)의 개요
• 현실 세계의 사물을 객체(데이터 + 메서드)로 모델링
• 소프트웨어의 재사용성, 확장성, 유지보수성 극대화
2. 객체 지향 4대 특징 ★★★
• 1. 추상화 (Abstraction): 핵심적이고 공통적인 특징만 추출
• 2. 캡슐화 (Encapsulation): 데이터와 함수 결합, 정보 은닉
• 3. 상속성 (Inheritance): 부모 클래스의 기능을 자식이 물려받아 재사용
• 4. 다형성 (Polymorphism): 같은 메시지에 대해 객체마다 다르게 반응
🧱 OOP 4대 기둥 정리
특징 핵심 정의 및 기출 키워드
추상화 불필요한 세부사항 배제, 본질적 공통점 모델링
캡슐화 ★ 데이터와 연산을 하나로 묶고 정보 은닉 보호
상속성 ★ 상위 클래스의 속성과 메서드를 그대로 물려받음
다형성 하나의 인터페이스로 다양한 구현 형태 지원
💡 기출 지문 정답: "객체 지향 프로그래밍의 특징이 아닌 것은? ➔ 순차성, 선형성은 절차형 언어의 특징입니다!"
TOPIC 51 • 운영체제 (OS) ★출제 1위

시스템 소프트웨어 & 성능 평가 4대 목적

1. 운영체제 (Operating System)의 정의
• 컴퓨터 하드웨어와 사용자 사이의 인터페이스 역할을 하는 시스템 소프트웨어
• 컴퓨터가 켜져 있는 동안 항상 주기억장치(RAM)에 상주하여 시스템 제어
2. 운영체제의 성능 평가 4대 목적 ★★★
• 1. 처리 능력 (Throughput): 일정 시간 내 작업 처리량 ➔ 향상 ↑
• 2. 반환 시간 (Turnaround Time): 작업 의뢰 후 결과 반환 시간 ➔ 단축(감소) ↓
• 3. 사용 가능도 (Availability): 즉시 사용 가능한 정도 ➔ 증대 ↑
• 4. 신뢰도 (Reliability): 작업을 정확히 해결하는 정도 ➔ 향상 ↑
🎯 OS 성능 평가 4대 기준 매트릭스
평가 기준 의미 목표 방향
처리 능력 단위 시간당 처리하는 일의 양 향상 (증가)
반환 시간 ★ 작업 지시부터 결과 출력까지 걸린 시간 단축 (감소)
사용 가능도 필요할 때 컴퓨터를 즉시 쓸 수 있는 비율 증대 (향상)
신뢰도 주어진 문제를 오차 없이 해결하는 정도 향상 (증가)
⚠️ 오답 함정 1위: "운영체제의 목적은 반환 시간(응답 시간)을 향상(증대)시키는 것이다" ➔ X (반환 시간은 짧을수록 좋으므로 '단축'되어야 함!)
TOPIC 51 • OS 프로그램 구성

제어 프로그램 vs 처리 프로그램

1. 제어 프로그램 (Control Program) ★암기
• 시스템의 작동 상태를 감시하고 작업의 원활한 진행 제어
• 1. 감시 프로그램 (Supervisor): OS의 핵심, 모든 동작 감독
• 2. 작업 관리 프로그램 (Job Management): 작업의 스케줄링
• 3. 데이터 관리 프로그램 (Data Management): 파일 및 입출력 관리
2. 처리 프로그램 (Processing Program)
• 제어 프로그램 지휘하에 실제 데이터 처리를 수행
• 언어 번역 프로그램, 서비스 프로그램, 문제 처리 프로그램
📂 운영체제 2대 프로그램 분류도
제어 프로그램 ★ 처리 프로그램
감시 프로그램 언어 번역 프로그램 (컴파일러 등)
작업 관리 프로그램 서비스 프로그램 (정렬, 유틸리티)
데이터 관리 프로그램 문제 처리 프로그램
💡 암기 팁: 제어 프로그램은 오직 3개: 감시, 작업, 데이터! 언어 번역 프로그램은 '처리 프로그램'에 속합니다.
TOPIC 52 • OS 운용 기법

운영체제 발전 순서 & 5대 운용 기법

1. 자료 처리 발전 순서 ★
• 일괄 처리 ➔ 실시간 처리 ➔ 시분할(TSS) ➔ 분산 처리
2. 대표 운용 방식 5가지
• 일괄 처리 (Batch): 데이터를 일정 기간 모아서 한꺼번에 처리 (급여 계산)
• 실시간 처리 (Real-Time): 발생 즉시 처리 (은행 잔고, 항공기 예약)
• 시분할 (Time Sharing): CPU 시간을 나누어 사용자에게 할당
• 임베디드 (Embedded): 가전, 자동차 등 기기 내부에 결합된 제어 시스템
🚗 임베디드 시스템(Embedded)의 특징
• 정의: 하드웨어와 소프트웨어가 하나로 결합된 특수 전자 제어 시스템
• 적용 분야: 스마트 TV, 냉장고, 자동차 ECU, 의료기기, 디지털 카메라
• 특징: 특정 기기의 제어 기능만을 수행하도록 최적화되어 작고 가벼움
💡 기출 지문 정답: "여러 명의 사용자가 동시에 컴퓨터를 사용할 수 있도록 CPU 시간을 나누어 할당하는 기법은 시분할 시스템(TSS)이다."
TOPIC 53 • 전원 보호 장치 ★출제 1위

UPS (무정전 전원) & AVR (자동 전압 조절)

1. UPS (무정전 전원 공급장치) ★★★
• 갑작스러운 정전(Blackout) 발생 시 배터리로 일정 시간 동안 컴퓨터에 전원을 공급
• 작업 중인 데이터를 저장하고 정상적으로 시스템을 종료할 수 있는 시간 확보
2. AVR (자동 전압 조절기)
• 입력 전압이 변동될 때 출력 전압을 항상 일정하게 유지해 주는 전압 조절 장치
3. CVCF & 서지 보호기
• CVCF: 전압과 주파수를 동시에 일정하게 유지
• 서지 보호기 (Surge Protector): 벼락/낙뢰 등의 순간적 고전압 차단
⚡ 전원 보호 장치 4총사 핵심 비교
장치 약어 장치 명칭 핵심 기능 및 대처 상황
UPS ★ 무정전 전원 공급장치 정전 시 일정 시간 동안 전원 공급
AVR 자동 전압 조절기 전압 변동을 일정 전압으로 유지
CVCF 정전압 정주파 장치 전압과 주파수 모두 일정 유지
Surge Protector 서지 보호기 낙뢰 등 급격한 과전압 유입 차단
💡 기출 지문 정답: "정전이 발생했을 때 컴퓨터가 꺼지지 않고 일정 시간 전원을 공급해 주는 장치는 UPS이다."

정답: O (정확한 설명!)
UPS(무정전 전원 공급장치)는 정전 시 배터리로 전원을 지속 공급해 줍니다!
