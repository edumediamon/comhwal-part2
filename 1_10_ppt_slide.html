TOPIC 60 • 검색 엔진

검색 엔진의 종류와 메타 검색

1. 키워드 vs 디렉터리 검색 엔진
• 키워드 검색: 검색 로봇(크롤러)이 문서를 수집하여 키워드로 검색
• 디렉터리 검색: 주제별·분야별 카테고리 계층 구조로 분류된 검색
2. 메타 검색 엔진 (Meta Search Engine, ★빈출)
• 자체 데이터베이스(색인)를 보유하지 않음
• 다른 여러 검색 엔진에 검색어를 동시 전송하여 결과를 취합/제공
3. 하이브리드 검색 엔진
• 키워드 검색 방식과 디렉터리 검색 방식을 결합하여 상호 보완한 검색 엔진
🔍 메타 검색 엔진의 동작 다이어그램 기출 핵심
사용자 검색어 입력 ("컴활 2급")

TOPIC 61 • 전자우편 (1)

전자우편 기본 구조와 7비트 ASCII

1. 전자우편의 기본 특성
• 송신자와 수신자가 동시에 접속해 있지 않아도 비동기 통신 가능
• 참조(Cc), 숨은 참조(Bcc)로 동시에 다수에게 발송 가능
2. 7비트 ASCII 표준 (★시험 단골)
• 전통적 전자우편 본문 규격은 7비트의 ASCII 문자를 기본 사용
• 8비트 한글이나 바이너리 파일 전송 시 인코딩 변환 필요
3. 계정 주소 형식
• 사용자ID@호스트컴퓨터도메인 (예: user@korea.com)
📧 수신인 지정 방식 비교
지정 방식 표시 여부 용도
받는 사람 (To) 모두에게 공개 직접적인 주 수신자
참조 (Cc) 모두에게 공개 업무 공유 대상자
숨은 참조 (Bcc) 다른 수신인에게 비공개 개인정보 보호 다량 발송
TOPIC 61 • 전자우편 프로토콜

전자우편 4대 프로토콜 매칭

📤 SMTP (Simple Mail Transfer Protocol)
• 사용자 컴퓨터에서 메일 서버로, 또는 서버 간에 메일을 보낼 때(송신) 사용하는 프로토콜
📥 POP3 (Post Office Protocol 3)
• 메일 서버에 도착한 메일을 사용자의 컴퓨터로 가져올 때(수신) 사용하는 프로토콜
🎨 MIME (Multipurpose Internet Mail Extensions)
• 텍스트 외에 사진, 동영상, 음성 등 멀티미디어 파일을 전송할 수 있게 확장해 주는 프로토콜
⚡ 1초 판별 프로토콜 매칭표 100% 출제
프로토콜 역할 키워드 출제 핵심
SMTP 송신 (보내기) 서버로 발송 및 서버 간 전송
POP3 수신 (받기) 서버에서 클라이언트로 다운로드
MIME 멀티미디어 전송 웹 브라우저 및 첨부파일 지원
IMAP 서버 동기화 수신 여러 기기에서 메일 관리
TOPIC 61 • 전자우편 분류

옵트인 메일 vs 스팸 메일

✅ 옵트인 메일 (Opt-In Mail)
• 수신자가 사전에 수신 동의(허가)를 명시적으로 표시한 광고 메일
• 뉴스레터, 정기 구독 안내문 등 합법적 마케팅 메일
🚫 스팸 메일 (Spam / Junk Mail)
• 수신자의 동의 없이 불특정 다수에게 일방적으로 발송되는 광고성 메일
• 흔히 정크 메일로도 불림
💣 폭탄 메일 (Mail Bomb)
• 시스템 마비를 목적으로 대량의 메일을 특정 메일 계정에 집중 전송하는 서비스 거부 공격
⚖️ 광고 메일 비교
구분 옵트인(Opt-In) 스팸(Spam)
사전 동의 동의 있음 (O) 동의 없음 (X)
발송 합법성 합법적 메일 불법 스팸 규제 대상
별칭 허가 메일 정크 메일(Junk)
TOPIC 62 • 인터넷 서비스

원격 접속(Telnet)과 유즈넷(Usenet)

🖥️ 텔넷 (Telnet, 원격 접속)
• 물리적으로 멀리 떨어진 원격지 컴퓨터 시스템에 접속하여 사용하는 원격 제어 프로토콜
• 텍스트 기반 가상 터미널 환경 제공
📰 유즈넷 (Usenet, 전자게시판)
• 공통 관심사를 가진 사용자들이 의견을 게시하고 정보를 공유하는 세계적 뉴스그룹 전자게시판
💬 IRC (Internet Relay Chat)
• 인터넷상에서 여러 사용자가 실시간으로 문자를 주고받으며 대화하는 채팅 서비스
🎯 서비스별 핵심 기능 매칭
서비스 기능 요약 기출 핵심 키워드
Telnet 원격 컴퓨터 접속 원격지 시스템 제어
Usenet 공통 주제 토론/게시판 뉴스그룹/전자게시판
IRC 실시간 문자 통신 대화(채팅) 시스템
FTP 파일 송수신 프로토콜 업로드/다운로드
TOPIC 62 • 파일 전송 프로토콜

FTP 파일 전송과 실행 원칙

1. FTP 기본 개념
• TCP/IP 네트워크상에서 컴퓨터 간에 파일을 송·수신(업로드/다운로드)하기 위한 표준 프로토콜
• 원칙적으로 FTP 서버 계정이 등록되어 있어야 접속 가능
2. 원격 실행 불가 원칙 (★출제 1위)
• FTP 서버에 있는 파일은 서버 상에서 직접 실행 불가!
• 반드시 로컬 PC로 다운로드한 후 실행해야 함
3. 2가지 전송 모드
• ASCII 모드: 텍스트 문서 파일 전송
• Binary 모드: 그림, 동영상, 압축파일, 실행파일(.exe) 전송
🚨 기출 오답 함정 주의보 함정 판별
단골 오답 지문
"FTP 서버에 저장된 실행 파일(.exe)은 다운로드하지 않고 서버에서 즉시 실행할 수 있다." ➔ 오답!
(반드시 다운로드 후 로컬에서 실행해야 함)
전송 모드 매칭
• 텍스트 문서 ➔ ASCII
• 실행파일/그림/음악 ➔ Binary (2진)
TOPIC 62 • 익명 파일 전송

익명(Anonymous) FTP 서비스

🔓 계정 없는 사용자 접근 허용
• 사용자 공식 계정이 없어도 FTP 서버의 공개된 파일에 자유롭게 접근할 수 있는 서비스
• 공개 소프트웨어, 기술 문서, 드라이버 배포에 주로 사용
🔑 접속 계정 정보 규격
• 아이디(User ID): anonymous 입력
• 비밀번호(Password): 관례상 자신의 이메일 주소 입력
🛡️ 권한 제한
• 대부분 읽기/다운로드 권한만 부여되며 임의의 업로드나 삭제는 제한됨
📊 일반 FTP vs 익명 FTP
구분 일반 FTP Anonymous FTP
사용자 계정 사전 등록된 전용 계정 계정 없이 접근 허용
로그인 ID 개인 사용자 ID anonymous
비밀번호 개인 비밀번호 자신의 E-mail 주소
TOPIC 63 • 기업 통신망

인트라넷 vs 엑스트라넷

🏢 인트라넷 (Intranet)
• 인터넷 기술(TCP/IP, 웹 브라우저)을 이용하여 구축한 기업 내부 전용 사설망
• 외부인의 접근이 철저히 차단된 사내 직원 전용 전자결재, 정보 공유망
🤝 엑스트라넷 (Extranet, ★출제 1순위)
• 인트라넷을 협력업체, 납품업체, 고객 등 승인된 외부 사용자에게까지 제한적으로 확장한 네트워크
• 기업 간 B2B 정보 교환 및 공급망 관리에 활용
🌐 네트워크 도메인 범위 다이어그램 핵심 비교
인터넷 (전 세계 개방망)
엑스트라넷 (협력업체/고객 확장)
인트라넷 (기업 내부 임직원 전용)
TOPIC 63 • 협업과 웹 호스팅

그룹웨어와 웹 호스팅 서비스

👥 그룹웨어 (Groupware, 협업 소프트웨어)
• 여러 구성원이 함께 일할 수 있도록 돕는 사내 협업 소프트웨어
• 전자결재, 문서 공유, 일정 관리, 메신저 등 의사결정의 신속성 지원
🌐 웹 호스팅 (Web Hosting)
• 자체 서버를 구축하기 어려운 개인이나 기업에게 대형 서버의 일정 저장 공간을 임대(빌려주는) 서비스
• 24시간 안정적인 고속 회선과 웹 사이트 운영 환경 제공
⚖️ 인트라넷 vs 그룹웨어 구분 출제 포인트
구분 인트라넷 그룹웨어
본질적 성격 네트워크 (망/인프라) 소프트웨어 (프로그램)
핵심 키워드 사내 전용 폐쇄망 전자결재, 협업 프로그램
관계 인트라넷 환경 위에서 그룹웨어 소프트웨어가 구동됨
TOPIC 63 • 통신 기술

인터넷 전화(VoIP)와 무선 회선(WLL)

📞 VoIP (Voice over Internet Protocol)
• 일반 전화망 대신 인터넷 IP 네트워크를 통해 음성 통화를 제공하는 기술 (인터넷 전화)
• 장거리 및 국제 전화 비용을 획기적으로 절감
📡 WLL (Wireless Local Loop, 무선 가입자 회선)
• 전화국 교환국과 가정/사무실 사이를 유선 케이블 대신 무선 신호로 연결하는 기술
• 유선 선로 가설이 어려운 도서·산간 지역에 신속 구축 가능
📹 넷미팅 (NetMeeting)
• 인터넷상에서 음성, 영상, 채팅, 화이트보드를 공유하는 화상 회의 통신 솔루션
🎯 1초 정의 매칭
용어 핵심 한 줄 정의
VoIP 인터넷망을 이용한 음성 통화(인터넷 전화)
WLL 전화국과 가입자 간을 잇는 무선 가입자 회선
넷미팅 인터넷을 이용한 화상/음성 다자간 회의
웹 호스팅 웹 사이트 운영용 서버 공간 임대 서비스
