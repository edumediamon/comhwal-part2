TOPIC 42 • 기타 장치

ROM BIOS & CMOS 하드웨어 설정

1. 바이오스 (BIOS, Basic Input Output System) ★
• 컴퓨터의 기본 입출력 시스템, ROM(플래시 메모리)에 저장
• 전원 켜짐 ➔ POST (전원 투입 자가 진단)를 통해 시스템 점검 ➔ OS 로드
2. CMOS 셋업 (Hardware Setup)
• 메인보드 CMOS 칩에 저장된 하드웨어 환경 설정을 변경하는 기능
• 설정 항목: 부팅 순서, 시스템 날짜/시간, 칩셋 설정, 전원 관리, 비밀번호
⚙️ BIOS vs CMOS 핵심 차이점
구분 저장 위치 핵심 기능
BIOS ★ ROM (비휘발성) 하드웨어 기본 제어, POST 부팅 점검
CMOS 메인보드 CMOS 칩 (배터리 유지) 사용자가 부팅 순서/암호/시간 변경
💡 기출 지문 정답: "컴퓨터 전원을 켤 때 시스템을 자가 진단(POST)하고 하드웨어를 초기화하는 BIOS는 ROM에 저장되어 있다."
TOPIC 43 • 입출력 포트 ★출제 1위

USB 포트 규격 & 127대 확장 공식

1. USB (Universal Serial Bus) 4대 특징 ★
• 최대 확장 개수: 허브를 통해 최대 127개까지 장치 연결 가능
• 핫 플러그인 (Hot Plug In): 전원이 켜진 상태에서 장치 연결/분리
• 플러그 앤 플레이 (PnP): 장치 연결 시 OS가 자동 인식 및 드라이버 구성
2. USB 버전별 색상 및 전송 속도 ★
• USB 2.0: 검은색(흰색) 단자, 최대 480 Mbps
• USB 3.0: 파란색 단자, 최대 5 Gbps (약 10배 고속)
🔌 USB 버전별 사양 비교
버전 단자 색상 최대 전송 속도
USB 2.0 검은색 / 흰색 480 Mbps
USB 3.0 ★ 파란색 (Blue) 5 Gbps (초고속)
HDMI 포트 - 영상 + 음성 무압축 디지털 전송
💡 기출 지문 정답: "USB 인터페이스는 핫 플러그인을 지원하며 하나의 포트에 허브를 통해 최대 127개의 장치를 연결할 수 있다."
TOPIC 44 • 시스템 제어 ★출제 빈출

인터럽트(Interrupt) & 3대 발생 유형

1. 인터럽트의 정의
• CPU 작업 도중 긴급 요청 발생 시 작업을 일시 중단하고 우선 처리 후 원래 작업으로 복귀
• 시스템 안정성을 유지하며, 컴퓨터를 재부팅할 필요 없음
2. 인터럽트 3대 분류 ★
• 외부 인터럽트: 전원 이상, 정전, 타이머, 입출력 장치 완료 등 외부 요인
• 내부 인터럽트 (트랩, Trap): 0으로 나누기, 오버플로, 잘못된 명령 실행
• 소프트웨어 인터럽트: 프로그램 처리 중 발생, SVC (Supervisor Call)
⚡ 인터럽트 유형별 발생 원인 매핑
인터럽트 종류 대표 발생 원인
외부 인터럽트 정전, 전원 이상, 키보드 입력, 타이머 시간 초과
내부 인터럽트 (트랩) ★ 0으로 나누기(Divide by Zero), 불법 연산
소프트웨어 인터럽트 감시 프로그램 호출 명령 (SVC 인터럽트)
💡 기출 지문 정답: "프로그램 실행 중 0으로 나누거나 잘못된 명령어를 사용할 때 발생하는 인터럽트는 내부 인터럽트(트랩)이다."
TOPIC 44 • 데이터 전송 ★출제 1위

DMA (직접 메모리 접근) & 채널(Channel)

1. DMA (Direct Memory Access) ★★★
• CPU를 거치지 않고 입출력 장치와 메모리가 직접 데이터 전송
• CPU의 입출력 간섭을 배제하여 컴퓨터 전체의 작업 효율 대폭 향상
2. 채널 (I/O Channel)
• CPU로부터 입출력 제어권을 넘겨받아 대신 수행하는 입출력 전용 프로세서
• 고속 CPU와 저속 입출력 장치 간의 속도 병목 현상 완화
3. 데드락 (Deadlock, 교착 상태)
• 서로 다른 프로그램이 자원을 점유한 채 상대방 자원을 기다리며 시스템이 멈추는 현상
🔄 일반 전송 vs DMA 전송 비교도
💡 기출 지문 정답: "CPU의 개입 없이 입출력 장치와 주기억장치 간에 직접 데이터를 주고받는 방식은 DMA이다."
TOPIC 45 • 소프트웨어 분류 ★출제 1위

상용·공개 & 셰어웨어(Shareware)

1. 상용 소프트웨어 (Commercial SW)
• 대가를 지불하고 정식 라이선스를 구매해야 사용 가능한 상용 제품 (예: MS Office, 한글)
2. 공개 소프트웨어 (Freeware, 프리웨어)
• 개발자가 비용 없이 누구나 무료로 자유롭게 사용하도록 허용한 소프트웨어
3. 셰어웨어·트라이얼 (Shareware·Trial) ★★★
• 일정 기간 동안 무료로 체험 사용한 후, 마음에 들면 구매하도록 유도
• 기간 만료 후 계속 사용하려면 정식 비용 지불 필요
💰 소프트웨어 구매 및 사용 조건 비교
소프트웨어 비용 지불 여부 사용 기간 / 조건
상용 소프트웨어 유료 구매 필수 영구 또는 정기 구독
공개 (프리웨어) 완전 무료 기간 제한 없이 사용
셰어웨어 ★ 체험 후 유료 결제 일정 기간 동안 구매 유도
트라이얼 체험 기간 무료 일정 기간 동안 체험판
💡 기출 지문 정답: "정식 구매를 유도하기 위하여 일정 기간 동안 무료로 사용해 볼 수 있도록 배포하는 프로그램은 셰어웨어이다."
TOPIC 45 • 테스트 및 패치 버전

알파·베타 버전 & 패치(Patch) 프로그램

1. 알파 버전 vs 베타 버전 ★
• 알파 버전 (Alpha): 개발사(회사 내부 직원)가 테스트하기 위한 시험판
• 베타 버전 (Beta): 정식 출시 전 일반 사용자들에게 배포하여 테스트하는 시험판
2. 패치 프로그램 (Patch Program) ★
• 기출시된 프로그램의 버그(오류) 수정, 보안 취약점 개선을 위해 배포하는 수정 프로그램
3. 데모(Demo) & 번들(Bundle)
• 데모: 제품 홍보용 맛보기 / 번들: 하드웨어 구매 시 무료로 끼워주는 SW
🎯 배포 목적별 소프트웨어 구분표
소프트웨어 배포 대상 및 목적
알파 버전 개발사 내부 직원 대상 자체 테스트
베타 버전 ★ 일반 사용자 대상 출시 전 오류 검증
패치 프로그램 ★ 기존 프로그램의 오류/버그 수정 및 개선
번들 소프트웨어 하드웨어 살 때 끼워주는 번들 프로그램
💡 기출 지문 정답: "소프트웨어의 오류를 수정하거나 보안 취약점을 해결하기 위해 배포하는 프로그램은 패치 프로그램이다."
TOPIC 46 • 유틸리티 & 압축

유틸리티 프로그램 & 파일 압축 원리

1. 유틸리티 프로그램 (Utility)의 정의
• 컴퓨터 시스템을 관리하고 편리하게 작업하도록 돕는 보조 프로그램
• 파일 압축기, 바이러스 백신, 텍스트 편집기, 이미지 캡처 도구 등
2. 파일 압축 프로그램의 핵심 원리 ★
• 데이터 중복을 제거하여 파일 크기를 줄이고 전송 속도 향상
• 주요 포맷: ZIP, RAR, 7Z, EGG, ARJ, LHA
• ⚠️ 한번 압축된 파일을 다시 재압축해도 크기는 거의 줄어들지 않음!

COMPARISON MATRIX

속도 병목 극복 3대 핵심 솔루션

1. 캐시 메모리 (Cache Memory)
• 위치: CPU ↔ 주기억장치 사이
• 해결: 초고속 CPU와 저속 DRAM 간의 속도 격차 완화 (SRAM 사용)
2. 버퍼 메모리 (Buffer) & 채널/DMA
• 버퍼: 서로 다른 두 장치 간의 속도 차이로 인한 데이터 완충
• DMA: CPU 경유 없이 메모리와 고속 데이터 직접 전송
⚡ 병목 해결 기술 한눈에 보기
기술 대상 장치 해결 방식
캐시 (Cache) CPU ↔ RAM 자주 쓰는 데이터 SRAM 임시 보관
버퍼 (Buffer) 임의의 두 장치 데이터 임시 완충 저장소
DMA ★ 입출력장치 ↔ RAM CPU 거치지 않고 직접 전송
채널 (Channel) 입출력 전용 CPU 대신 입출력 제어 전담

Q1. USB의 최대 장치 확장 한도
"USB 인터페이스는 허브를 이용할 경우 최대 255개까지 장치를 연결하여 확장할 수 있다." (O / X?)
정답: X (최대 127개!)
USB는 하나의 컨트롤러당 최대 127개까지 포트 확장이 가능합니다!
Q2. BIOS의 저장 위치
"컴퓨터 기본 입출력 시스템인 BIOS는 전원이 차단되면 내용이 지워지는 휘발성 RAM에 저장된다." (O / X?)
정답: X (비휘발성 ROM에 저장!)
BIOS는 부팅 시 항상 읽어야 하므로 비휘발성 메모리인 ROM(플래시 메모리)에 저장됩니다!
Q3. DMA의 CPU 경유 여부
"DMA 방식은 대용량 데이터 전송 시 반드시 CPU의 레지스터를 경유하여 메모리로 이동한다." (O / X?)
정답: X (CPU 거치지 않음!)
DMA는 CPU를 거치지 않고(미경유) 입출력장치와 메모리가 직접 데이터를 전송합니다!
