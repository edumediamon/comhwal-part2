TOPIC 13 • 시스템 (SYSTEM)

디스플레이 & 장치 사양 정보

1. 디스플레이 (Display) 설정
• 화면 밝기, 야간 모드, HDR, 텍스트 배율, 해상도 및 화면 방향 설정
• 2대 이상 모니터 연결 시 디스플레이 식별·배치 및 다중 디스플레이 표시 방식(복제/확장) 지정
2. 정보 (About) — 하드웨어 & OS 사양
• 장치 사양: 장치 이름, 프로세서(CPU), 설치된 RAM, 시스템 종류(64/32비트) 확인
• Windows 사양: 에디션, 버전, 설치 날짜 등 확인 및 PC 이름 바꾸기 지원
3. 그 외 주요 시스템 기능
• 소리, 알림, 집중 지원, 전원 및 배터리, 저장소, 원격 데스크톱, 클립보드 관리

TOPIC 14 • 개인 설정 (PERSONALIZATION)

바탕 화면 배경, 테마 & 잠금 화면

1. 배경 & 테마 (Theme)
• 배경: 단색, 사진, 슬라이드 쇼, Windows 추천 등으로 바탕 화면 변경
• 테마: 배경, 테마 색, 소리, 마우스 커서 등을 한 번에 묶어서 종합 설정
2. 잠금 화면 & 화면 보호기
• 잠금 화면 이미지 선택 및 잠금 화면에 상태를 표시할 앱(날씨, 일정 등) 선택
• 화면 보호기(Screen Saver) 설정 지원
3. 시작 & 작업 표시줄 편집
• 시작 메뉴 항목 배치, 최근 추가된 앱 표시 여부
• 작업 표시줄 정렬(가운데/왼쪽), 작업 표시줄 자동 숨기기 설정

TOPIC 14 • 글꼴 (FONTS) ★출제 1위

글꼴 설치 경로 & 4대 확장자 규격

1. 글꼴의 기본 설치 위치 (암기 필수)
• 경로: C:\Windows\Fonts 폴더에 저장
• 시스템에 설치된 모든 글꼴 파일이 중앙 집중 보관되는 장소
2. 글꼴 추가 및 제거 관리
• 글꼴 추가: 글꼴 파일을 Fonts 폴더로 드래그 앤 드롭하거나 마우스 우클릭 [설치]
• 글꼴 제거: 필요 없는 글꼴을 선택하여 언제든지 삭제(제거) 가능
3. 지원하는 4대 글꼴 파일 확장자
• OTF, TTC, TTF, FON (4가지 확장자 완벽 암기!)
🔤 글꼴(Font) 확장자 및 시험 정답 공식

.OTF

.FON

설치된 앱 제거·수정 & 기본 앱 지정

• 컴퓨터에 설치된 프로그램을 제거(삭제)하거나 수정
• 앱 설치 위치 지정 및 고급 옵션을 통한 앱 초기화/복구 지원

• 특정 작업 및 파일 형식에 대해 자동으로 실행될 기본 응용 프로그램 지정
• 대상 작업: 웹 브라우저, 전자 메일, 지도, 음악 플레이어, 비디오 플레이어, 사진 뷰어
3. 파일 형식/프로토콜별 연결 프로그램
• .pdf, .mp4, .html 등 특정 확장자별로 실행할 기본 앱 매핑 가능

TOPIC 15 • 시작 프로그램 (STARTUP)

부팅 자동 실행 관리 & 성능 최적화

1. 시작 프로그램의 정의
• Windows 부팅(로그온) 시 자동으로 실행되도록 등록된 응용 프로그램
• 메신저, 백신, 클라우드 동기화 앱 등이 주로 등록됨
2. 부팅 속도 개선 및 메모리 관리
• 시작 프로그램이 많으면 부팅 시간이 지연되고 RAM 메모리 점유율 증가
• 불필요한 시작 프로그램을 '끔(사용 안 함)'으로 변경하면 부팅 속도 개선
3. 관리 위치 (2가지 경로)
• 경로 1: [Windows 설정] ➔ [앱] ➔ [시작 프로그램]
• 경로 2: [작업 관리자](Ctrl+Shift+Esc) ➔ [시작 앱] 탭
🚀 시작 프로그램 관리 시뮬레이터
앱 이름 시작 시 영향 상태
Windows Security 낮음 켜짐 (필수)
Microsoft OneDrive 중간 켜짐
불필요한 메신저/유틸 높음 (지연 유발) 끔 (비활성화 권장)
💡 주의: 시작 프로그램을 비활성화한다고 해서 프로그램이 컴퓨터에서 삭제되는 것은 아니며, 부팅 시 자동 실행만 중단됩니다.
TOPIC 16 • 접근성 (ACCESSIBILITY) ★

접근성 단축키 +U & 시각/청각 보조

1. 접근성의 정의와 목적
• 신체에 장애가 있거나 컴퓨터 사용이 익숙하지 않은 사람을 위한 환경 지원
• 단축키: + U (Accessibility 즉시 실행)
2. 시각 보조 기능
• 돋보기 (++): 화면의 특정 영역 또는 전체 확대
• 내레이터: 화면의 텍스트와 UI 요소를 음성으로 읽어주는 기능
• 고대비 / 텍스트 커서: 명암 대비를 높여 시인성 개선
3. 청각 보조 기능
• 오디오 자막: 소리를 화면에 텍스트 자막으로 변환 표시
• 시각적 알림: 소리 재생 시 활성 창이나 화면 전체를 깜빡이게 설정
👁️ 시각/청각 접근성 보조 도구 요약
보조 도구 핵심 기능 및 특징
돋보기 화면의 특정 부분이나 전체를 최대 1600%까지 확대 표시
내레이터 ★ 시각 장애인을 위해 화면의 모든 글자를 음성으로 낭독
고대비 색상 구분이 어려운 사용자를 위해 흑백/고채도 색상 배합 적용
자막/깜빡임 청각 장애인을 위해 시스템 소리를 텍스트나 화면 점멸로 대체
💡 기출 지문 정답: "화면의 텍스트를 음성으로 읽어주는 접근성 보조 프로그램은 내레이터(Narrator)이다."
TOPIC 16 • 입력 보조 기능 ★최다 빈출

키보드·마우스 4대 보조 기능

1. 고정 키 (Sticky Keys) ★
• Ctrl, Alt, Shift, 처럼 두 개 이상의 키를 동시에 누르기 힘들 때
• 키를 하나씩 차례대로 눌러도 조합 키가 동작하도록 지원
2. 토글 키 (Toggle Keys) ★
• Caps Lock, Num Lock, Scroll Lock 누를 때 신호음(삐 소리) 발생
3. 필터 키 & 4. 마우스 키 ★
• 필터 키: 짧거나 반복된 키 입력을 무시하여 잘못된 입력 방지
• 마우스 키: 마우스 대신 숫자 키패드로 마우스 포인터 이동 및 클릭
⌨️ 접근성 4대 입력 보조 기능 비교 매트릭스
기능명 대상 키 작동 방식 및 시험 정답
고정 키 Ctrl, Shift, Alt, Win 동시에 누르지 않고 차례대로 누름
토글 키 Caps/Num/Scroll Lock 누를 때마다 소리(신호음)로 알림
필터 키 모든 키보드 자판 반복되거나 짧은 키 입력 무시
마우스 키 숫자 키패드 (NumPad) 숫자 키패드로 마우스 커서 조작
💡 기출 지문 정답: "Ctrl+Alt+Del 처럼 여러 키를 동시에 누르기 어려운 사용자를 위한 기능은 고정 키이다."
TOPIC 17 • 사용자 계정 (ACCOUNTS)

관리자 계정 vs 표준 사용자 계정

1. 관리자 계정 (Administrator) — 완전한 제어
• 시스템 설정 변경, 프로그램/하드웨어 설치 및 제거
• 다른 사용자 계정 관리, 보안 권한 등 컴퓨터의 모든 자원을 완벽하게 관리
2. 표준 계정 (Standard User) — 제한된 사용
• 일상적인 작업(앱 실행, 파일 작성, 개인 설정)은 가능
• 시스템 설정 변경, 프로그램 설치/제거, 보안 작업 등 중요 권한 제한
3. 사용자 계정 컨트롤 (UAC) 팝업
• 표준 사용자가 관리자 권한 작업 시도시 관리자 암호 입력 창 표시
👤 계정 유형별 권한 비교 매트릭스
작업 유형 관리자 계정 표준 계정
일반 소프트웨어 실행 및 문서 작성 O (가능) O (가능)
새 프로그램 및 하드웨어 드라이버 설치 O (가능) X (제한됨)
다른 사용자 계정 추가/삭제/변경 O (가능) X (불가)
Windows 방화벽 및 시스템 보안 변경 O (가능) X (불가)
💡 기출 지문 정답: "표준 계정 사용자는 컴퓨터의 보안 설정이나 시스템 소프트웨어 설치를 임의로 수행할 수 없다."
TOPIC 18~19 • 보안 & 업데이트

개인정보 보안 권한 & Windows 업데이트

1. Windows 보안 (통합 보안 센터)
• 바이러스 및 위협 방지: 악성 코드 실시간 검사 및 치료
• 방화벽 및 네트워크 보호: 인가되지 않은 외부 침입 차단
• 앱 및 브라우저 컨트롤: 위험한 사이트 및 다운로드 차단
2. 앱 사용 권한 (개인 정보 보호)
• 앱별로 카메라, 마이크, 위치, 연락처, 파일 시스템, 생성형 AI 등의 접근 권한을 개별적으로 허용하거나 차단
3. Windows 업데이트의 목적
• 보안 취약점 수정, 버그 패치, 최신 기능 및 드라이버 설치로 운영체제를 안전하고 최신 상태로 유지

TOPIC 20 • 장치 관리자 (DEVICE MANAGER) ★

하드웨어 상태 점검 & 상태 기호 3대 공식

1. 장치 관리자의 주요 역할
• 컴퓨터에 설치된 모든 하드웨어 디바이스 목록 확인
• 드라이버 소프트웨어 업데이트, 롤백, 제거
• 문제가 발생한 하드웨어의 오류 상태 진단 및 문제 해결
2. 물음표(?) vs 느낌표(!) 암기 공식 ★
• 물음표( ? ): 드라이버 미설치 또는 장치 정보 불완전
• 느낌표( ! ): 드라이버 충돌/인식 오류로 하드웨어 정상 작동 불가
3. 아래 화살표 ( ↓ ) 기호의 의미
• 고장이 아니며, 사용자가 '디바이스 사용 안 함(비활성화)'으로 설정함
⚠️ 장치 관리자 기호별 의미 완벽 비교
기호 표시 상태 발생 원인 및 시험 핵심 정답
? 물음표 드라이버가 설치되지 않았거나 장치 정보 불완전
! 느낌표 드라이버 미설치·충돌·인식 오류로 정상 작동 안 됨
↓ 아래 화살표 사용자가 수동으로 '디바이스 사용 안 함' 설정
⚠️ 오답 함정 1위: "물음표(?)는 사용자가 장치를 사용 안 함으로 설정한 것이다" ➔ X (사용 안 함은 아래쪽 화살표 ↓ !)
