TOPIC 06 • 폴더 옵션

폴더 옵션의 3대 설정 탭

1. [일반] 탭 — 실행 및 창 열기 방식
• 창 열기: 같은 창에서 폴더 열기 vs 새 창에서 폴더 열기
• 클릭해서 항목 열기: 한 번 클릭(포인팅 선택) vs 두 번 클릭(더블클릭)
2. [보기] 탭 — 파일·폴더 표시 규칙
• 숨김 파일, 폴더 및 드라이브 표시 여부 지정
• 알려진 파일 형식의 파일 확장명 숨기기 설정
• 보호된 운영 체제 파일 숨기기(권장)
3. [검색] 탭 — 검색 동작 규칙
• 색인된 위치에서 파일 이름 및 내용 검색 포함 여부 설정
📂 폴더 옵션 탭별 설정 매트릭스
탭 이름 핵심 설정 항목 기출 확인 포인트
[일반] 탭 창 열기(같은창/새창), 클릭 방식 실행 환경 동작 제어
[보기] 탭 숨김 파일, 확장명 표시/숨김 확장자 표시 여부는 [보기] 탭!
[검색] 탭 색인 위치, 파일 내용 검색 검색 범위 및 속도 조절
💡 기출 지문 정답: "파일 확장자를 표시하거나 숨기려면 폴더 옵션의 [보기] 탭에서 설정한다."
TOPIC 07 ★ 시험 단골

파일명 작성 규칙 & 금지 특수문자 9개

1. 파일 이름 글자수 규격
• 공백, 한글, 영문, 특수문자 포함 최대 255자까지 지정 가능
• 경로(드라이브+폴더+파일명) 전체 길이는 최대 제한 있음
2. 파일명에 절대 사용할 수 없는 9대 특수문자
• \ / : * ? " < > | (9개 문자 사용 불가!)
• 경로 구분자: \, /, :
• 와일드카드 및 기호: *, ?, ", <, >, |

TOPIC 07 ★ 기출 1순위

같은/다른 드라이브 이동과 복사 공식

1. 마우스 그냥 드래그 앤 드롭 (기본 동작)
• 같은 드라이브 내에서 드래그 ➔ 이동 (Move)
• 다른 드라이브(C ➔ D)로 드래그 ➔ 복사 (Copy) ★
2. 단축키 조합 강제 조작
• Ctrl + 드래그 ➔ 드라이브 상관없이 무조건 복사(+)
• Shift + 드래그 ➔ 드라이브 상관없이 무조건 이동

TOPIC 07 • 선택 & 클립보드

선택 단축키 & 클립보드 (Clipboard)

1. 마우스 선택 보조키 역할
• Ctrl : 비연속적인 파일 선택, 기존 선택 항목 일부 해제
• Shift : 처음과 끝을 연결하는 연속적인 파일 선택(클릭)
• Alt : 파일 선택·이동·복사와 아무 관련 없음!
2. 클립보드(Clipboard)의 동작 원리
• 복사(Ctrl+C)·잘라내기(Ctrl+X) 데이터의 임시 보관소
• Windows에 설치된 모든 앱에서 공유 및 다회 사용 가능
• 컴퓨터 재시작 시 데이터 소멸 (휘발성 메모리)
⚡ 화면 캡처 클립보드 단축키 비교

TOPIC 08 • 휴지통 기본

휴지통의 규격 & 용량 초과 처리 법칙

1. 휴지통 용량 설정
• 각 드라이브 용량의 기본 5~10% 배정
• 드라이브마다 크기를 다르게 한 개씩 설정 가능
• 사용자가 원하는 메가바이트(MB) 단위 크기 지정 가능
2. 용량 초과 시 자동 처리 (★최다 출제)
• 휴지통 용량이 가득 차면 에러가 발생하는 것이 아니라,
• 가장 오래전에 삭제된 파일부터 자동으로 영구 삭제하고 최근 파일 보관!
3. 휴지통 내부 파일 제약
• 휴지통 안의 파일은 실행, 복사, 이름 바꾸기 불가!
• 반드시 [복원]을 해야만 정상 사용 가능

TOPIC 08 ★ 기출 1순위 (최다 빈출)

휴지통 미보관 즉시 영구 삭제 5대 경우

★ 무조건 시험에 나오는 영구 삭제 5대 케이스
① Shift + Delete 로 강제 삭제한 경우
② USB 메모리, 외장 플래시 드라이브에서 삭제한 경우
③ 네트워크 드라이브(공유 폴더)에서 삭제한 경우
④ DOS(명령 프롬프트) 모드에서 del 명령으로 삭제한 경우
⑤ 휴지통 속성에서 '버리지 않고 바로 제거' 체크 또는 용량 0MB 지정
기억할 핵심 팩트
위 5가지 경우로 삭제된 파일은 휴지통을 통해 복원할 수 없습니다!
⚡ 휴지통 보관 vs 영구 삭제 판정표
삭제 환경 및 방법 휴지통 보관 여부 복원 가능 여부
C 드라이브에서 그냥 [Delete] 보관됨 (O) 휴지통에서 복원 가능
Shift + [Delete] 미보관 (X) 즉시 영구 삭제
USB 메모리에서 삭제 미보관 (X) 즉시 영구 삭제
네트워크 공유 폴더 삭제 미보관 (X) 즉시 영구 삭제
명령 프롬프트(DOS) 삭제 미보관 (X) 즉시 영구 삭제
⚠️ 시험 정답: USB 메모리와 네트워크 드라이브는 로컬 하드가 아니므로 휴지통을 지원하지 않습니다!
TOPIC 09 • 기본 보조프로그램

메모장 특징 & .LOG 시간 자동 기록

1. 메모장에서 절대 안 되는 것 (★출제 1위)
• 그림, 차트, 표, OLE 개체 삽입 불가!
• 메뉴 모음에 [삽입] 메뉴 자체가 없음
• 서식 없는 순수 텍스트(.TXT) 위주 작성
2. 현재 날짜/시간 삽입 2대 공식
• 자동 기록: 첫 행 맨 왼쪽에 .LOG (대문자) 입력 시 열 때마다 자동 기록!
• 수동 삽입: 단축키 F5 누르면 현재 시간/날짜 삽입

TOPIC 12 ★ 기출 1순위 (초빈출)

인쇄 관리자 & 스풀 (Spool) 기능

1. 인쇄 관리자 (Print Manager)
• 인쇄 진행 상태, 대기열 문서 확인
• 인쇄 대기 문서의 일시 중지, 취소, 다시 시작 가능
2. 스풀(SPOOL) 기능의 본질 (★핵심)

KILLER TRAP 01

시험 직전 3초 판별 킬러 함정 ①

파일명·드라이브·휴지통 기출 함정
실제 시험 지문에서 가장 자주 혼동을 일으키는 대표 오답 보기 3가지입니다. 카드를 클릭하여 3초 만에 O/X를 판별해 보세요!
Q1. 파일 이름에 별표(*) 사용 가능 여부
"Windows 파일 및 폴더 이름에는 별표(*)와 물음표(?) 문자를 자유롭게 포함할 수 있다." (O / X?)
정답: X (절대 사용 불가!)
와일드카드 문자인 * 와 ? 를 포함한 9대 특수문자는 파일명에 절대로 사용할 수 없습니다!
Q2. 다른 드라이브로 그냥 마우스 드래그 시 동작
"C 드라이브의 파일을 D 드라이브로 단축키 없이 그냥 마우스 드래그하면 '이동'된다." (O / X?)
정답: X ('복사'가 기본 동작!)
같은 드라이브는 이동이지만, 서로 다른 드라이브 간에는 복사가 일어납니다!
Q3. USB 메모리에서 삭제한 파일의 휴지통 보관
"USB 메모리에 저장된 문서를 Delete 키로 삭제하면 컴퓨터 휴지통에 안전하게 보관된다." (O / X?)
정답: X (즉시 영구 삭제!)
USB 메모리나 외장 드라이브, 네트워크 공유 폴더에서 삭제한 파일은 휴지통에 보관되지 않고 즉시 삭제됩니다!
KILLER TRAP 02

시험 직전 3초 판별 킬러 함정 ②

메모장·기본프린터·스풀 기출 함정
수험생들이 가장 쉽게 속는 매력적인 오답 보기 3가지입니다. 카드를 클릭하여 정확한 정답을 확인해 보세요!
Q1. 메모장의 그림 및 OLE 개체 삽입 여부
"메모장은 [삽입]-[그림] 메뉴를 이용하여 사진이나 OLE 개체를 자유롭게 포함할 수 있다." (O / X?)
정답: X (그림/OLE 개체 삽입 불가!)
메모장은 순수 텍스트 전용 앱이므로 그림, 표, 차트, OLE 개체는 절대로 삽입할 수 없습니다!
Q2. 기본 프린터 복수 지정 가능 여부
"필요에 따라 컬러 프린터와 흑백 프린터 2대를 동시에 기본 프린터로 지정할 수 있다." (O / X?)
정답: X (오직 1대만 지정 가능!)
프린터 드라이버는 여러 개 설치할 수 있지만, 기본 프린터는 반드시 1대만 지정할 수 있습니다!
Q3. 스풀(Spool) 기능과 인쇄 속도
"스풀 기능을 사용하면 프린터의 인쇄 속도가 획기적으로 향상되어 빠르게 출력된다." (O / X?)
정답: X (인쇄 속도는 향상되지 않음!)
스풀은 컴퓨터 전체의 처리 효율(CPU 활용)을 높이는 것이지, 프린터의 기계적 인쇄 속도는 빨라지지 않습니다!
