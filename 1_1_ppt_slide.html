TOPIC 01 ★ 출제 1순위

한글 Windows의 4대 핵심 아키텍처

1. 그래픽 사용자 인터페이스(GUI)
• 창·아이콘·메뉴·포인터 등의 그래픽 요소를 이용하여 컴퓨터를 조작하는 방식
• 과거 DOS(CUI, 문자 명령 인터페이스)와 구별!
2. 선점형 멀티태스킹 (Preemptive)
• 운영체제가 CPU 제어권을 강제 주도함!
• 특정 앱 오류 시 해당 앱만 강제 종료 가능 (시스템 전체 다운 방지)
3. 플러그앤 플레이(Plug & Play) & 핫 스왑
• PnP: 하드웨어 장치 연결 시 자동 인식 및 드라이버 설치
• 핫 스왑(Hot Swap): 시스템을 종료하지 않고 장치를 교체할 수 있는 기능
⚡ 선점형 vs 비선점형 멀티태스킹 비교
구분 선점형 (Windows) ★ 비선점형 (과거 OS)
CPU 주도권 운영체제(OS)가 강제 회수 실행 중인 프로그램이 독점
오류 발생 시 해당 문제 프로그램만 강제 종료 시스템 전체 다운 (블루스크린)
응답성 높음 (부드러운 멀티태스킹) 특정 작업 완료 시까지 대기
💡 기출 지문 정답: "한 프로그램이 CPU를 독점하지 못하도록 운영체제가 실행 시간을 할당하는 방식은 선점형 멀티태스킹이다."
TOPIC 01 • 파일 시스템

NTFS vs FAT32 결정적 차이점

1. NTFS (New Technology File System) ★기본
• Windows 기본 파일 시스템으로 대용량 볼륨/파일 지원
• 보안(사용자 권한), 파일 암호화(EFS), 압축 지원
• 디스크 할당량(Quota) 및 트랜잭션 복구로 높은 안정성
2. FAT32 (File Allocation Table 32)
• 단일 파일 최대 크기 4GB 제한 (고화질 동영상 저장 불가)
• 보안/암호화 기능 지원하지 않음
• 다양한 기기(스마트TV, 차량용 내비 등)와의 호환성은 우수
📊 기출 1순위 파일 시스템 비교 매트릭스
비교 항목 NTFS (추천★) FAT32 (구형)
단일 파일 크기 최대 16TB (제한 없음 수준) 최대 4GB 제한! ★
보안 / 권한 사용자별 권한 / 암호화 지원 안 함 (접근제어 불가)
디스크 할당량 지원 (사용자별 용량 제한) 지원 안 함
파일 압축 폴더/파일 단위 압축 지원 지원 안 함
⚠️ 오답 함정: "FAT32는 4GB 이상의 대용량 파일을 저장할 수 있다" ➔ X (절대 저장 불가)
TOPIC 01 • 화면 관리

스냅 레이아웃 & 에어로 피크

1. 스냅 레이아웃 (Snap Layouts)
• 여러 창을 격자 형태로 즉시 화면 분할 배치
• 단축키: + Z (또는 최대화 버튼 호버)
2. 에어로 피크 (Aero Peek) ★빈출
• 열린 창을 투명화하여 바탕 화면을 빠르게 확인
• 단축키: + D (바탕 화면 표시)
3. 기타 윈도우 11 편의 기능
• 위젯: + W | 빠른 설정: + A
• OLE(개체 삽입과 연결): 워드에 엑셀 표를 연동 삽입

TOPIC 03 ★ 빈출문제

바로 가기 아이콘 (.LNK)의 특징

1. 바로 가기 아이콘의 정의
• 원본 파일의 위치 경로만 저장한 링크 파일
• 왼쪽 아래에 화살표 모양(↗) 표시, 확장자는 .LNK
• 하나의 원본 파일에 대해 위치 제한 없이 여러 개 생성 가능
2. 원본과 바로 가기 아이콘의 삭제 법칙 (★최다 빈출)
• 원본 파일 삭제 시: 바로 가기 아이콘은 실행 불가(연결 끊김)
• 바로 가기 아이콘 삭제 시: 원본 파일은 절대 삭제 안 됨!

TOPIC 05 ★ 시험 단골

파일 탐색기 구조 & 탐색 단축키

1. 파일 탐색기의 기본 구조 (+E)
• 왼쪽(탐색 창): 계층적 트리 디렉터리 구조로 표시
• 오른쪽(폴더 내용 창): 선택된 폴더 내의 파일과 하위 폴더 내용 표시

• * (숫자패드 별표) : 선택 폴더의 모든 하위 폴더 표시★

KILLER TRAP 01

시험 직전 3초 판별 킬러 함정 ①

Windows 특징 & 파일 시스템 기출 함정
실제 시험 지문에서 수험생들이 가장 많이 낚이는 대표 오답 보기 3가지입니다. 우측의 카드를 클릭하여 정답을 맞춰보세요!
Q1. 플러그 앤 플레이(PnP) 드라이버 설치 여부
"PnP 장치를 연결하면 사용자가 반드시 제조사 웹사이트에서 드라이버를 수동 설치해야 한다." (O / X?)
정답: X (운영체제가 자동 인식 및 설치!)
PnP는 하드웨어를 꽂기만 하면 운영체제가 자동으로 감지하여 적절한 드라이버를 설치해 주는 기능입니다!
Q2. FAT32 파일 시스템의 단일 파일 크기 한계
"FAT32 파일 시스템은 10GB 용량의 대용량 동영상 단일 파일을 문제없이 저장할 수 있다." (O / X?)
정답: X (단일 파일 최대 4GB 제한!)
FAT32는 하나의 파일 크기가 최대 4GB로 제한되어 10GB 파일은 복사 자체가 거부됩니다. 대용량은 NTFS를 써야 합니다!
Q3. 바로 가기 아이콘 삭제와 원본 파일
"바탕 화면의 바로 가기 아이콘(.LNK)을 삭제하면 원본 프로그램 파일도 하드디스크에서 함께 삭제된다." (O / X?)
정답: X (원본 파일은 안전하게 보존!)
바로 가기 아이콘은 위치 링크 정보만 가진 1KB짜리 껍데기 파일이므로 삭제해도 원본에는 아무 영향이 없습니다!

정답: X (Alt + Enter 가 정답!)
Alt + Tab은 열려 있는 프로그램 창 전환 키이며, 속성 대화상자는 Alt + Enter 입니다!
Q2. 마우스 우클릭 [바로 가기 메뉴] 키보드 단축키
"선택한 항목에 대한 바로 가기(컨텍스트) 메뉴를 표시하는 단축키는 Shift + F10 이다." (O / X?)
정답: O (완전 맞는 보기!)
마우스 오른쪽 단추 클릭 기능의 키보드 단축키는 Shift + F10 이 맞습니다!
Q3. 파일 탐색기에서 모든 하위 폴더 표시 키
"선택된 폴더의 모든 하위 폴더를 한꺼번에 표시하는 키는 숫자패드의 '+' 키이다." (O / X?)
정답: X (숫자패드 '*' 별표 키!)
'+' 키는 한 단계 하위 폴더만 열어주며, 모든 단계의 하위 폴더를 전부 펼치는 키는 숫자패드의 * (별표) 입니다!
