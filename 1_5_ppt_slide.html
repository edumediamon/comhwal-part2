TOPIC 29 • 자료 표현 단위 ★암기 필수

자료 표현 단위 8단계 크기 순서

1. 자료 표현 단위 크기 공식 (작음 ➔ 큼)
• 비트(Bit) < 니블(Nibble) < 바이트(Byte) < 워드(Word) < 필드(Field) < 레코드(Record) < 파일(File) < 데이터베이스(DB)
2. 물리적 단위 (Bit ~ Word)
• 비트: 정보 표현의 최소 단위 (0, 1)
• 니블: 4 Bit (16가지 표현)
• 바이트: 문자 표현의 최소 단위 (8 Bit)
• 워드: CPU가 한 번에 처리하는 명령 단위
3. 논리적 단위 (Field ~ Database)
• 필드(항목): 파일 구성의 최소 단위 ➔ 레코드 ➔ 파일 ➔ 데이터베이스

          ▲

          ▲
        🏷️ Field (Item) (파일 구성의 최소 단위)

[최하위] 💡 Bit (자료 표현의 최소 단위, 0/1)
TOPIC 29 • 세부 규격 분석

바이트(Byte) & 워드(Word)의 핵심 규격

1. 바이트 (Byte) — 문자 표현 최소 단위 ★
• 1 Byte = 8 Bit ➔ 28 = 256가지 정보 표현
• 영문자 / 숫자 / 특수기호: 1 Byte 소모
• 한글 / 한자: 2 Byte 소모 (시험 단골 정답!)
2. 워드 (Word) — CPU 처리 단위
• CPU가 한 번의 연산으로 처리할 수 있는 데이터의 폭
• 반워드 (Half Word): 2 Byte (16 Bit)
• 전워드 (Full Word): 4 Byte (32 Bit)
• 더블워드 (Double Word): 8 Byte (64 Bit)
📏 바이트 및 문자 표현 크기 비교
문자 유형 소모 바이트 소모 비트 수
영문자 (A, b, c) 1 Byte 8 Bit
숫자 (0 ~ 9) 1 Byte 8 Bit
한글 (가, 나, 다) ★ 2 Byte 16 Bit
한자 (漢, 字) ★ 2 Byte 16 Bit
💡 기출 계산 문제: "컴퓨터에서 'KOREA대한민국'을 저장하는 데 필요한 바이트 수는?" ➔ KOREA(5B) + 대한민국(8B) = 13 바이트!
TOPIC 30 • 용량 & 속도 단위 ★

1024배수 용량 & 초고속 처리 단위(ms~as)

1. 기억 용량 단위 (1024 = 210 배수)
• Byte ➔ KB (210) ➔ MB (220) ➔ GB (230) ➔ TB (240) ➔ PB (250) ➔ EB (260)
• 1 KB = 1,024 Byte (2진수 기준)
2. 컴퓨터 처리 속도 단위 (느림 ➔ 빠름) ★
• ms (10-3) ➔ μs (10-6) ➔ ns (10-9) ➔ ps (10-12) ➔ fs (10-15) ➔ as (10-18)
• 밀리(ms) ➔ 마이크로(μs) ➔ 나노(ns) ➔ 피코(ps) ➔ 펨토(fs) ➔ 아토(as)
⚡ 처리 속도 단위 지수 비교 매트릭스
기호 단위 명칭 시간 (초) 속도 비교
ms 밀리초 (Millisecond) 10-3 초 가장 느림
μs 마이크로초 (Microsecond) 10-6 초 ▲
ns 나노초 (Nanosecond) 10-9 초 ▲
ps 피코초 (Picosecond) 10-12 초 ▲
fs 펨토초 (Femtosecond) 10-15 초 ▲
as 아토초 (Attosecond) 10-18 초 가장 빠름
💡 기출 지문 정답: "처리 속도가 빠른 것부터 나열한 것은?" ➔ ps(피코초) > ns(나노초) > μs(마이크로초) > ms(밀리초)!
TOPIC 31 • 문자 표현 코드 ★최다 빈출

ASCII 7비트 vs 유니코드 2바이트

1. BCD 코드 (6 Bit) — 64문자
• Zone 2비트 + Digit 4비트 = 6비트 (26 = 64개 표현)
• 영문 소문자를 구별하지 못함
2. ASCII 코드 (7 Bit) — 128문자 ★
• Zone 3비트 + Digit 4비트 = 7비트 (27 = 128개 표현)
• 미국 표준, 대소문자 구별, 데이터 통신용, 일반 PC 문자 코드
• 오류 검출용 1비트 패리티를 붙여 확장형(8비트)으로 전송 가능
3. EBCDIC (8 Bit) & 유니코드 (2 Byte) ★
• EBCDIC: 8비트 (256개), 대형 컴퓨터용
• 유니코드(Unicode): 국제 표준, 2바이트(16비트, 65,536문자) 전 세계 문자 표현
🔡 4대 문자 표현 코드 비교 매트릭스
코드명 비트 수 표현 문자 수 주요 특징 및 출제 포인트
BCD 6 Bit 64개 영문 소문자 표현 불가
ASCII ★ 7 Bit 128개 일반 PC, 데이터 통신용, 대소문자 구별
EBCDIC 8 Bit 256개 대형 컴퓨터용 확장 BCD
유니코드 ★ 2 Byte (16b) 65,536개 국제 표준, 한글/한자/외국어 통합
💡 기출 지문 정답: "일반 개인용 컴퓨터에서 널리 사용되며 데이터 통신용으로 7비트를 사용하는 코드는 ASCII 코드이다."
TOPIC 32 • 에러 검출 코드 ★기출 1순위

패리티 비트(검출) vs 해밍 코드(교정)

1. 패리티 비트 (Parity Bit) — 단순 검출용
• 1의 개수가 짝수(우수) 또는 홀수(기수)가 되도록 1비트 추가
• 에러 발생 여부만 '검출' 가능
• 어느 비트가 틀렸는지 알 수 없어 '에러 교정 불가'!
2. 해밍 코드 (Hamming Code) — 검출 + 교정 ★
• 오류 발생 위치를 찾아내어 에러 '검출 및 자동 교정(수정)' 수행
• 시험에 "에러 교정" 단어가 나오면 무조건 해밍 코드!
3. 기타 오류 검사 방식
• CRC (순환 중복 검사): 다항식 코드를 이용한 신뢰성 높은 검사
• 블록합 검사 (BSC): 2차원 패리티 검사 방식
🛡️ 에러 검출 코드 핵심 비교
코드 종류 에러 검출 에러 교정
패리티 비트 O (가능) X (불가 ★)
해밍 코드 ★ O (가능) O (가능 ★)
순환중복(CRC) O (가능) X (재전송 요청)
💡 기출 지문 정답: "데이터 통신 중 오류를 스스로 검출하고 수정(교정)까지 할 수 있는 코드는 해밍 코드이다."
TOPIC 33 • 진수 변환 공식

2진수를 8진수 & 16진수로 쾌속 변환

1. 2진수 ➔ 8진수 변환 (3자리 묶음) ★
• 8 = 23 이므로, 2진수를 뒤에서부터 3자리씩(4, 2, 1) 묶어서 계산
• 예: 11 101 101(2) ➔ (2+1) / (4+0+1) / (4+0+1) = 355(8)
2. 2진수 ➔ 16진수 변환 (4자리 묶음) ★
• 16 = 24 이므로, 2진수를 뒤에서부터 4자리씩(8, 4, 2, 1) 묶어서 계산
• 10=A, 11=B, 12=C, 13=D, 14=E, 15=F
• 예: 1010 0101(2) ➔ (8+2=10 ➔ A) / (4+1=5) = A5(16)
🔢 16진수 표기법 (10 ~ 15 알파벳)
10 = A
11 = B
12 = C
13 = D
14 = E
15 = F
💡 암기 공식: 8진수는 3비트씩 묶고, 16진수는 4비트씩 묶는다!
TOPIC 34 • CPU 구조 (PROCESSOR)

CPU 3대 구성 & 레지스터·성능 단위

1. CPU의 3대 핵심 구성 요소
• 제어장치 (CU): 명령어를 인출·해독하고 모든 장치에 제어 신호 전달
• 연산장치 (ALU): 산술 연산(+,-,*,/) 및 논리 연산(AND, OR, NOT) 수행
• 레지스터 (Register): CPU 내부의 초고속 임시 기억 장소
2. CPU 성능 평가 단위 ★
• MIPS: 초당 100만 개 명령어 처리 단위 (Million Instructions Per Second)
• FLOPS: 초당 부동소수점 연산 횟수 (과학기술 계산)
• 클럭 속도 (Hz): CPU의 1초당 동작 주기 주파수 (GHz)

TOPIC 35 • 제어장치 레지스터 ★출제 1위

프로그램 카운터(PC) vs 명령 레지스터(IR)

1. 프로그램 카운터 (PC, Program Counter) ★★★
• 다음에 실행될 명령어의 번지(주소)를 기억하는 레지스터
• 명령어가 하나 인출되면 자동으로 값이 증가하여 다음 명령을 가리킴
2. 명령 레지스터 (IR, Instruction Register) ★
• 현재 실행 중인 명령어 코드를 임시로 저장하는 레지스터
3. MAR & MBR
• MAR (메모리 주소 레지스터): 읽기/쓰기할 데이터의 기억장치 주소 보관
• MBR (메모리 버퍼 레지스터): 기억장치와 주고받는 실제 데이터 임시 보관
⚖️ PC vs IR 기출 정답 완벽 대비표
레지스터 기억 대상 핵심 키워드 및 시험 정답
프로그램 카운터 (PC) 다음 명령 주소 "다음에 실행할 명령어의 번지를 기억"
명령 레지스터 (IR) 현재 명령 코드 "현재 실행 중인 명령어를 임시 저장"
메모리 주소 (MAR) 기억장치 주소 주소 버스와 연결된 번지 기억
메모리 버퍼 (MBR) 실제 데이터 내용 데이터 버스와 연결된 자료 임시 기억
💡 기출 지문 정답: "다음에 실행할 명령어의 번지(주소)를 기억하는 레지스터는 프로그램 카운터(PC)이다."
TOPIC 35 • 제어 회로 (CIRCUITS)

명령 해독기(디코더) & 부호기(인코더)

1. 명령 해독기 (Decoder) ★
• 명령 레지스터(IR)에 있는 명령어를 해독하는 회로
• 2진수 명령어 코드를 해독하여 어떤 동작을 수행할지 판별
2. 부호기 (Encoder) ★
• 해독된 명령에 따라 각 장치로 보낼 제어 신호를 생성·발생시키는 회로
3. 제어장치 명령어 실행 흐름도
• PC(다음주소) ➔ 메모리 인출 ➔ IR(현재명령저장) ➔ 해독기(명령해독) ➔ 부호기(제어신호발생)
🔄 제어장치 명령어 처리 파이프라인
1️⃣ PC (프로그램 카운터): 다음 실행할 주소 지정
    ▼
2️⃣ MAR ➔ MBR: 주기억장치에서 명령 읽어옴
    ▼
3️⃣ IR (명령 레지스터): 현재 명령 보관
    ▼
4️⃣ 명령 해독기 (Decoder): 명령의 종류 해독
    ▼
5️⃣ 부호기 (Encoder): 각 장치로 제어 신호 전달!
💡 기출 지문 정답: "해독된 명령어에 따라 각 장치로 보낼 제어 신호를 생성하는 회로는 부호기(Encoder)이다."

Q1. 16진수 변환 시 비트 묶음
"2진수를 16진수로 변환할 때는 2진수를 오른쪽 끝에서부터 3자리씩 묶어서 계산한다." (O / X?)
정답: X (16진수는 4자리씩 묶음!)
3자리씩 묶는 것은 8진수이며, 16진수는 4자리(8,4,2,1)씩 묶어야 합니다!
Q2. 프로그램 카운터(PC)의 역할
"프로그램 카운터(PC)는 현재 CPU에서 실행 중인 명령어 자체를 임시 보관하는 레지스터이다." (O / X?)
정답: X (현재 실행은 IR!)
현재 실행 명령은 명령 레지스터(IR)이며, PC는 '다음에 실행할 명령의 주소'를 기억합니다!
Q3. 레지스터의 접근 속도
"컴퓨터의 기억 장치 중 CPU 내부에 있는 레지스터(Register)가 접근 속도가 가장 빠르다." (O / X?)
정답: O (압도적 1위 속도!)
레지스터 > 캐시 메모리(SRAM) > 주기억장치(DRAM) > 보조기억장치 순서로 빠릅니다!
