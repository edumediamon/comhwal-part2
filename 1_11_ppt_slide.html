TOPIC 64 • 웹 언어

웹 언어와 HTML5 웹 표준

1. HTML (HyperText Markup Language)
• 하이퍼링크와 멀티미디어를 표현하는 기본 웹 문서 제작 언어
• 단순 텍스트 형식으로 호환성이 뛰어나고 누구나 작성 가능
2. HTML5 (★출제 1위)
• W3C에서 제정한 차세대 웹 표준 규격
• 액티브X(ActiveX) 등 플러그인 없이 동영상·음악을 브라우저에서 직접 재생 지원
3. DHTML / WML / VRML
• DHTML: 사용자와 상호작용하는 동적인 웹 페이지 구현
• WML: 스마트폰, PDA 등 무선 인터넷 기기 전용 언어
• VRML: 웹상에서 3차원 가상공간을 상호작용하는 언어
💡 HTML5 핵심 출제 키워드 기출 빈출
HTML5의 결정적 특징
• 표준화된 <video>, <audio> 태그 기본 탑재
• 플래시(Flash)나 액티브X 없이 완벽한 멀티미디어 구동
• 모바일과 PC에서 동일하게 동작하는 반응형 웹 표준
WML vs VRML
• WML: Wireless (무선 모바일용)
• VRML: Virtual Reality (3차원 가상현실)
TOPIC 65 • 정보 전송 방식

정보 전송 방식 3대 유형 비교

1. 단방향 통신 (Simplex)
• 오직 한 방향으로만 전송 가능 (송신측/수신측 고정)
• 대표 예시: 라디오(Radio), TV 방송
2. 반이중 통신 (Half-Duplex)
• 양방향 통신 가능하나, 동시 전송은 불가능 (교대로 전송)
• 대표 예시: 무전기 (Walkie-Talkie)
3. 전이중 통신 (Full-Duplex)
• 동시에 양방향 송수신이 모두 가능한 통신
• 대표 예시: 전화기, 스마트폰 통화
📻 1초 판별 통신 방식 표 100% 출제
전송 방식 양방향 여부 동시 전송 대표 기기
단방향 (Simplex) 단방향만 X 라디오, TV
반이중 (Half) 양방향 가능 동시 불가 (교대) 무전기
전이중 (Full) 양방향 가능 동시 가능 (O) 전화기
TOPIC 66 • 통신망 구성 방식

클라이언트/서버 vs P2P (동배간)

🖥️ 클라이언트 / 서버 (Client / Server)
• 클라이언트: 서비스를 요청하고 결과를 표시
• 서버: 대용량 데이터베이스와 자원을 보유하고 요청에 응답
• 전형적인 중앙 집중 및 분산 처리 환경에 적합
🤝 동배간 처리 방식 (Peer to Peer, P2P)
• 네트워크의 모든 컴퓨터가 동등(Peer)한 권한 보유
• 서버와 클라이언트의 구분이 없음 (동시에 송수신 수행)
• 파일 공유 프로그램(토렌트 등)에 주로 활용
⚖️ 핵심 구조 차이 비교
구분 클라이언트/서버 동배간 (P2P)
역할 구분 요청자 / 제공자 명확 구분 없음 (모두 동등)
자원 집중 중앙 서버에 집중 각 노드에 분산
전용 서버 반드시 필요함 필요 없음
TOPIC 67 • 통신망 구성 형태 (1)

통신망 구성 형태 5대 토폴로지

1. 성형 (Star, 중앙 집중형)
• 모든 단말기가 중앙 컴퓨터(호스트)에 1:1 포인트 투 포인트로 연결
2. 버스형 (Bus) & 링형 (Ring)
• 버스형: 하나의 공통 주 통신 회선에 여러 장치를 연결 (비용 저렴)
• 링형: 원형 루프를 형성하여 데이터를 한 방향 또는 양방향 순차 전송
3. 망형 (Mesh) & 트리형 (Tree)
• 망형: 모든 노드를 상호 연결하여 우회 경로가 풍부함 (신뢰성 최고)
• 트리형: 나뭇가지 형태의 계층적 분기 구조 (확장 용이)
🗺️ 5대 토폴로지 한 줄 요약
토폴로지 연결 외형 핵심 장점
성형 (Star) 중앙 허브 집결 유지보수, 확장 편리
버스형 (Bus) 단일 회선 공유 설치 비용 가장 저렴
링형 (Ring) 원형 고리 루프 데이터 충돌 적음
망형 (Mesh) 그물망 다중 연결 신뢰성 및 장애 극복 최고
트리형 (Tree) 계층적 분기 구조 네트워크 확장성 우수
TOPIC 67 • 통신망 구성 형태 (2)

성형 vs 망형 기출 킬러 포인트

⭐ 성형 (Star)의 치명적 결함
• 중앙 장치 점검과 보수는 쉽지만,
• 중앙 컴퓨터(허브) 고장 시 전체 통신망이 전면 마비됨!
🕸️ 망형 (Mesh)의 압도적 신뢰성
• 장치 간에 복수의 우회 경로가 존재하므로 장애에 가장 강하고 신뢰성이 가장 높음
• 단점: 회선 수가 많아 배선 구조가 복잡하고 설치 비용이 가장 비쌈

TOPIC 68 • 통신망의 범위

지리적 범위별 통신망 5단계

1. LAN (Local Area Network, 근거리 통신망)
• 한 건물, 사무실, 학교 캠퍼스 등 가까운 거리(구내)를 연결한 고속 네트워크
• 자원 공유 및 파일 전송에 최적화
2. MAN & WAN (도시권 및 광역망)
• MAN: 한 도시(Metropolitan) 단위의 통신망
• WAN: 국가, 대륙 등 매우 넓은 지역을 연결하는 광역 통신망
3. VAN (Value Added Network, 부가가치 통신망)
• 회선 임대 후 정보 가공·저장 등 새로운 부가가치를 부여하여 재판매하는 망
📏 통신망 규모 순서도
PAN (개인 10m) ➔ LAN (구내/건물) ➔ MAN (도시) ➔ WAN (국가/대륙) ➔ GAN (전 지구)
약어 명칭 적용 범위
LAN 근거리 통신망 사무실, 연구소, 학교 구내
WAN 광역 통신망 국가 간, 대륙 간 (인터넷)
VAN 부가가치 통신망 통신망 임대 + 가공 정보 제공
TOPIC 69 • 네트워크 장비 (1)

네트워크 접속 장비 5총사

1. 허브 (Hub)
• 여러 컴퓨터를 한 네트워크에 묶어 통합 관리하는 집선 장비
2. 리피터 (Repeater)
• 전송 거리가 멀어져 약해진 신호를 증폭하고 정형화하여 재생
3. 브리지 (Bridge)
• 동종 프로토콜의 분리된 근거리 통신망(LAN) 구간들을 상호 연결

TOPIC 69 • 네트워크 장비 (2)

라우터 vs 게이트웨이 맞대결

🧭 라우터 (Router, ★출제 1위)
• 서로 다른 네트워크 연결 반드시 필요한 장비
• 네트워크 계층(IP 계층)에서 동작하며 트래픽 분산 제어
🚪 게이트웨이 (Gateway)

• 서로 다른 언어를 번역해 주는 관문 역할을 수행

TOPIC 70 • 모바일 통신 장비

모바일 네트워크 주요 접속 장비

1. AP (Access Point)
• 유선 네트워크 케이블과 스마트폰·노트북 등 무선 단말기를 연결해 주는 기지국 역할
2. 무선 공유기 (Wireless Router)
• 1개의 인터넷 회선을 여러 무선/유선 기기가 공유하여 사용할 수 있게 IP를 분배
3. 무선 LAN 카드 & 모뎀
• 무선 LAN 카드: 단말기에서 Wi-Fi 신호를 수신하는 네트워크 인터페이스
• 이동통신 모뎀: 이동통신망(LTE, 5G) 신호를 통해 인터넷에 접속

TOPIC 72 • 무선 통신 기술

NFC, 블루투스, 테더링 기술

💳 NFC (Near Field Communication, ★빈출)
• 13.56MHz 주파수를 사용하는 10cm 이내의 비접촉식 근거리 무선통신
• 교통카드, 모바일 결제(삼성페이/애플페이), 도어록 등에 활용
📶 블루투스 (Bluetooth)
• 2.4GHz ISM 대역을 이용해 모바일 기기 간 선 없이 정보를 교환하는 근거리 무선 기술
• 무선 이어폰, 스마트워치, 무선 키보드 연결
🔗 테더링 (Tethering)
• 스마트폰의 모바일 데이터를 다른 컴퓨터나 태블릿과 공유하여 인터넷 사용 지원

기술명 유효 거리 대표 활용 분야
