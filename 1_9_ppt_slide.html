TOPIC 54 • RESOURCE MANAGEMENT

디스크 부족 vs 메모리 부족 조치

📁 디스크(저장공간) 용량 부족 시
• 디스크 정리 수행하여 불필요한 임시 파일 영구 삭제
• 휴지통 비우기 수행으로 용량 반환
• 사용하지 않는 앱(프로그램) 제거 수행
🧠 주기억장치(RAM) 메모리 부족 시
• 불필요하게 켜진 프로그램 종료 및 시스템 재부팅
• 부팅 시 자동 실행되는 시작 프로그램 해제/삭제
• 가상 메모리(페이징 파일) 크기 확장 또는 RAM 증설
⚖️ 자원 부족별 대응 비교표 혼동 주의
구분 해결 조치
디스크 부족 디스크 정리, 파일 삭제, 앱 제거
메모리 부족 프로그램 종료, 시작프로그램 정리
가상 메모리 메모리(RAM) 부족 시 크기 확대

TOPIC 55 • DISK MANAGEMENT (1)

디스크 검사 vs 디스크 포맷

🔍 디스크 검사 (오류 검사)
• 디스크 표면의 논리적·물리적 오류 및 불량 섹터를 찾아 복구
• 손상된 클러스터를 찾아 데이터를 다른 곳으로 이동
• 주의: 바이러스 검사 및 예방은 절대 불가능!
💾 디스크 포맷 (Format)
• 트랙과 섹터를 만들어 디스크를 초기화
• 파일 시스템(NTFS, FAT32)을 지정하여 파일 기록 환경 구축
• 파티션 분할 후 반드시 포맷을 거쳐야 사용 가능
🚨 기출 킬러 함정 포인트 오답 방지
오답 선지 1위
"디스크 검사를 실행하면 최신 바이러스에 감염된 파일을 탐지하여 치료할 수 있다." ➔ 완전 오답!
(바이러스 치료는 백신 프로그램 전용 기능임)
포맷 시 파일 시스템
• NTFS: 대용량 지원, 보안 및 권한 설정, 파일 암호화 지원
• FAT32: 호환성 우수하나 단일 파일 4GB 제한
TOPIC 55 • DISK MANAGEMENT (2)

디스크 정리의 대상과 제외 항목

🧹 디스크 정리의 핵심 목적
• 디스크의 불필요한 파일을 제거하여 저장 공간(여유 공간)을 확보
• 시스템 동작에 필수적이지 않은 캐시/임시 파일을 안전하게 소거
✅ 디스크 정리 포함 대상
• 임시 인터넷 파일, 휴지통 파일
• 다운로드한 프로그램 파일, 오프라인 웹 페이지
• 시스템 오류 메모리 덤프 파일, 설치 로그 파일
❌ 디스크 정리 대상이 아닌 것 (★시험 출제)
• 사용하지 않는 글꼴(Font)
• 사용하지 않는 응용 프로그램(앱)

TOPIC 55 • BACKUP & RESTORE

시스템 백업과 복원 지점

📦 백업 (Backup)
• 불의의 하드웨어 손상, 바이러스 등에 대비하여 파일이나 시스템 복사본 생성
• 원본과 다른 드라이브나 외부 저장장치에 보관 권장
🔄 복원 (Restore) & 복원 지점
• 시스템 변경 전으로 복원 지점(Restore Point)을 생성해 되돌림
• 시스템에 의해 자동 설정되거나 사용자가 수동 설정 가능
⚠️ 개인 파일 영향 없음 (기출 킬러)
• 시스템 복원은 사용자의 개인 파일(문서, 사진 등)은 복구하거나 삭제하지 못함!
🛡️ 복원 시 복구되는 항목 vs 안 되는 항목
구분 영향 여부 상세 대상
복원 대상 (O) 이전 상태로 복원 시스템 파일, 레지스트리, 드라이버, 설치 프로그램
복원 제외 (X) 영향 없음 개인 문서(HWP, XLSX), 사진, 이메일, 다운로드 파일
TOPIC 56 • NEXT-GEN NETWORK

차세대 IP 주소 IPv6 핵심 스펙

1. 비트 수와 표기 형식
• 총 128비트 길이 (기존 IPv4는 32비트)
• 16비트씩 8개 그룹으로 나뉘며 콜론(:)으로 구분
• 각 그룹은 4자리 16진수로 표현, 연속된 0은 생략 가능 (::)
2. 우수한 특징과 호환성
• IPv4와 호환성이 뛰어나며 전송 속도, 보안성(IPSec), 확장성 우수
3. IPv6의 3대 전송 방식
• 유니캐스트(1:1), 멀티캐스트(1:N), 애니캐스트(1:가장 가까운 노드)
• 브로드캐스트(Broadcast) 없음!
🌐 IPv4 vs IPv6 비교표 100% 출제
비교 항목 IPv4 IPv6
주소 길이 32비트 128비트
구성 체계 8비트 × 4개 부분 16비트 × 8개 부분
구분 기호 마침표 ( . ) 콜론 ( : )
진법 표기 10진수 16진수
전송 방식 유니/멀티/브로드 유니/멀티/애니
TOPIC 57 • DOMAIN NAME & DNS

도메인 네임과 DNS 서버

🔤 도메인 네임 (Domain Name)
• 숫자로 된 IP 주소를 사람이 기억하기 쉽도록 문자로 바꾼 인터넷 주소
• 전 세계 도메인 총괄 관리 ➔ ICANN
• 대한민국 국가 도메인(.kr) 관리 ➔ KISA (한국인터넷진흥원)
🔄 DNS (Domain Name System)
• 문자로 된 도메인을 컴퓨터가 통신할 수 있는 숫자 IP 주소로 상호 변환
• 인터넷 주소창에 도메인 입력 시 DNS 서버를 거쳐 IP를 조회함
🗺️ DNS의 변환 흐름도
사용자 입력: www.test.co.kr (문자 도메인)
⬇ (DNS 조회 변환)
실제 통신: 211.234.120.10 (숫자 IP 주소)
관리 기관 암기 팁
• 국제 도메인 총괄: ICANN
• 국내 .kr 도메인: KISA
TOPIC 57 • URL STRUCTURE

URL 표준 형식과 프로토콜 종류

📌 URL 표준 표기 형식
• 프로토콜://호스트 주소[:포트 번호][/경로][/파일명]
• 예시: https://www.example.com:443/docs/index.html
🌐 주요 프로토콜 종류
• http:// : 일반 웹 문서 전송 (포트 80)
• https:// : 보안 암호화 웹 전송 (포트 443)
• ftp:// : 대용량 파일 송수신 (포트 21)
• telnet:// : 원격지 컴퓨터 텍스트 접속 (포트 23)
• mailto: : 전자우편 링크
🔍 URL 구성 요소 분해
구성 요소 예시 설명

포트 번호 :443 서비스 포트 (생략 가능)

OSI 7계층과 대표 네트워크 장비

📶 계층 순서 암기 공식 (물-데-네-전-세-표-응)
• 1계층 물리 ➔ 2계층 데이터 링크 ➔ 3계층 네트워크
• ➔ 4계층 전송 ➔ 5계층 세션 ➔ 6계층 표현 ➔ 7계층 응용

• 물리 계층: 리피터(신호 증폭), 허브

TOPIC 59 • WEB BROWSER FEATURES

웹 브라우저 캐싱과 쿠키

⚡ 캐싱 (Caching)
• 자주 방문하는 웹 페이지의 리소스를 로컬 디스크에 임시 보관
• 재접속 시 서버를 거치지 않고 로컬에서 로딩하여 웹 페이지 표시 속도 대폭 향상
🍪 쿠키 (Cookie)
• 웹 서버가 사용자의 하드디스크에 저장하는 작은 기록 파일
• 사용자 아이디, 장바구니, 접속 이력 등을 기억하여 자동 로그인 및 맞춤 설정 지원
🪞 미러 사이트 & 포털 사이트
• 미러 사이트: 접속 폭주를 막고 부하를 분산하기 위해 원본 사이트를 그대로 복제
• 포털 사이트: 검색, 메일, 뉴스, 쇼핑 등을 하나로 묶어 제공하는 관문 사이트
